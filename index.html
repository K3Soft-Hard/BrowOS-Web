Sticky notes

0 notes

Drag widgets and notes by their title bar. Right-click the desktop to add a note quickly. The weather widget uses the city chosen in the Weather app.

Shortcuts

Click a key combination, then press the new keys. Backspace clears it and Esc cancels. Shortcuts work on the desktop and in the apps that come with BrowOS, not while a website app has the focus.

Data

Save all your settings, app folders, files, notes, profiles, and customizations to a single JSON backup file, or restore everything from one.

Updates & reset

Refresh updates clears only cached HTML, CSS, and JS files and reloads BrowOS while keeping your apps, notes, PIN, and settings. Reset all data completely erases all website data and restarts initial setup (Main profile only).

OS Security Code

Append this 5-digit code to the end of your recovery master password when unlocking or resetting via recovery.html. If someone sees it, regenerate a new code without resetting any data.
